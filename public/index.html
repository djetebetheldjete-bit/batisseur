Exporter ton projet

Emporte ton projet pour le rendre indépendant (son propre serveur, sa propre adresse). Télécharge les fichiers ci-dessous, puis suis le guide.

1 — Télécharger mon application (index.html) 2 — Le serveur (server.js) 3 — La base de données (schema.sql) 4 — package.json ★ Le guide complet (README.md)
En bref : mets index.html dans un dossier public/, place server.js à côté, puis lance node server.js sur ton ordinateur, ou déploie sur Render (GitHub + Render). Pour des données permanentes, crée une base Supabase avec schema.sql. Tout est expliqué pas à pas dans le README.

Bienvenue sur Bâtisseur — guide rapide

      
Bâtisseur t'aide à créer de vrais sites et applications, ou à apprendre à programmer — en discutant, pas à pas. Voici l'essentiel.

      

        

          1. Choisir quoi faire
          
Clique sur « Recommencer » : créer un site/app, apprendre à programmer, coder ton projet toi-même, ou l'atelier avancé (sur sélection).

        

        

          2. Construire en discutant
          
Explique ton idée en français. L'assistant construit, tu vois le résultat dans « Aperçu », et tu l'améliores en continuant à discuter (ex. « mets le titre en bleu »).

        

        

          3. Les boutons utiles
          
Exemples : des modèles pour s'inspirer. Mon espace : tous tes projets enregistrés. Les coulisses : comprendre le code derrière ton projet. Publier / Exporter : mettre en ligne ou rendre ton projet indépendant.

        

        

          4. Sur téléphone
          
Utilise les onglets Parcours · Discussion · Aperçu en haut pour passer d'un écran à l'autre.

        

      

      
Un doute ? Pose ta question à l'assistant dans la discussion, ou demande à ton formateur. Bon travail !

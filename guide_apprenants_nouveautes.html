Deux nouveautés pour aller plus loin

Guide rapide pour les apprenants de Bâtisseur

Tu as construit un projet, ou tu veux coder par toi-même ? Voici deux nouveaux espaces : l'un pour comprendre ce qu'il y a derrière ton application, l'autre pour réaliser ton projet toi-même, accompagné pas à pas.

Nouveau

Les coulisses — comprends ton application

Curieux de savoir ce qui crée ton interface, tes couleurs, tes boutons ? Ouvre les coulisses de ton projet et découvre le code derrière chaque partie.

  1. Ouvre un projet que tu as construit (depuis « Mon espace »).
  2. Dans la zone d'aperçu, clique sur le bouton « Les coulisses ».
  3. Explore les quatre onglets à ton rythme.
Mon projet expliquéUne explication claire et personnalisée de TON application.
Les grands blocsLes idées de base : mise en page, couleurs, boutons, données…
Le codeLe vrai code de ton application, à lire tranquillement.
Mes questionsPose une question sur ton code : la réponse reste enregistrée.
Astuce : l'explication et les réponses sont enregistrées. Tu peux les rouvrir autant de fois que tu veux — c'est gratuit. (Le nombre de nouvelles questions est limité par projet.)
Nouveau

Coder mon projet moi-même

Tu veux écrire le code toi-même ? Décris ton idée : tu reçois un plan pour la réaliser, un éditeur pour écrire et exécuter ton code, et un mentor qui te guide sans faire le travail à ta place.

  1. Clique sur « Recommencer », puis choisis « Coder mon projet moi-même ».
  2. Choisis ton langage (JavaScript ou Python).
  3. Donne le nom de ton projet et décris ton idée en une ou deux phrases.
  4. Lis ton plan de réalisation, puis code étape par étape dans l'éditeur (bouton « Exécuter »).
Un plan clairLes technologies, les étapes dans l'ordre, les fichiers à créer.
Un éditeur + une consoleÉcris ton code et exécute-le tout de suite pour voir le résultat.
Un mentorIl répond à tes questions et corrige tes erreurs, par petits pas.
EnregistréTon plan et tes échanges sont gardés : reprends quand tu veux.
Le mentor ne code pas à ta place : il t'apprend à construire ton projet morceau par morceau. C'est comme ça qu'on progresse vraiment !

Une question ? Demande à ton formateur. Bon travail, et amuse-toi à construire. — Bâtisseur
